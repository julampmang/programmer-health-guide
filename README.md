# 程序员健康管理指南

> 写给长期久坐、盯着屏幕、靠外卖续命的开发者：用工程师的方式管理身体。

体检报告上的箭头、下午三点的困倦、越来越僵的腰颈，都不是"矫情"，而是系统在报警。这个仓库把程序员最常见的健康问题拆成可执行的文档：**脂肪肝、血脂异常、高尿酸、久坐、护眼与颈腰、睡眠、体检、12 周行动方案**。

> ⚠️ **免责声明**：本仓库是健康科普，不构成医疗建议。具体诊断、用药和运动处方请咨询医生或专业教练。指标参考范围因实验室而异，请以你的体检报告为准。

## 指标速查

把最近一次体检报告拿出来，对照下表。箭头只是提示，**是否异常、是否需要治疗，必须由医生结合病史判断**。

| 指标 | 一般参考范围 | 需要关注 | 对应章节 |
| --- | --- | --- | --- |
| BMI | 18.5–23.9 | ≥24 超重，≥28 肥胖（中国标准） | [久坐与运动](docs/04-sedentary.md) |
| 腰围 | 男 <90 cm，女 <85 cm | 超标提示中心型肥胖 | [脂肪肝](docs/01-fatty-liver.md) |
| 血压 | <120/80 mmHg 理想 | ≥130/80 需复查，≥140/90 就诊 | [体检清单](docs/07-checkup.md) |
| ALT / AST | 约 7–40 U/L（因实验室而异） | 持续升高 | [脂肪肝](docs/01-fatty-liver.md) |
| 甘油三酯 TG | <1.7 mmol/L | ≥2.3 明显升高 | [血脂](docs/02-lipids.md) |
| LDL-C | 一般 <3.4 mmol/L | 高危人群目标更低 | [血脂](docs/02-lipids.md) |
| HDL-C | >1.0 mmol/L | 偏低常见于久坐 | [血脂](docs/02-lipids.md) |
| 血尿酸 | 男 <420，女 <360 μmol/L | ≥540 或痛风发作需就医 | [高尿酸](docs/03-uric-acid.md) |
| 空腹血糖 | 3.9–6.1 mmol/L | ≥7.0 需就诊 | [体检清单](docs/07-checkup.md) |
| 糖化血红蛋白 | <5.7% | ≥6.5% 需就诊 | [体检清单](docs/07-checkup.md) |
| eGFR | ≥90 mL/min/1.73m² | 持续下降需肾内科评估 | [体检清单](docs/07-checkup.md) |

## 三个核心原则

1. **先测量，再改变**：没有基线就没有反馈。先做一次体检，记录体重、腰围、步数和睡眠。
2. **小到不可能失败**：不要同时戒糖、健身、早睡。一次只加一个习惯，坚持两周再加下一个。
3. **系统大于意志力**：把水杯放在手边、把升降桌设成 45 分钟提醒、把零食从工位清走。环境设计比自律可靠。
