# 08 · 12 周执行方案：从体检报告到习惯

> **一句话结论**：不要一次改十件事。12 周只做三件事——**戒含糖饮料、每天打断久坐、每周两次力量训练**，其余习惯围绕它们生长。

## 第 0 周：建立基线

- [ ] 做一次体检（或找出最近一次报告），记录 ALT、TG、LDL-C、尿酸、空腹血糖、HbA1c、血压、腰围
- [ ] 早晨空腹称体重、量腰围
- [ ] 用手机或手环记录 3 天步数，取平均
- [ ] 记录 3 天睡眠时长和入睡时间
- [ ] 拍一张工位照片，对照 [工位五分钟自检](05-eyes-neck-back.md#工位五分钟自检) 调整
- [ ] 在日历上固定三个运动时段（每段 30–40 分钟）

## 第 1–2 周：只加一个习惯

**主题：把液体换掉，把久坐打断。**

- [ ] 戒掉所有含糖饮料（奶茶、可乐、果汁、运动饮料），改白水、无糖茶、黑咖啡
- [ ] 买一个 1 L 的水杯，每天喝 2–3 杯
- [ ] 每 50 分钟起身 2–3 分钟（用 [health-cli](https://github.com/julampmang/health-cli) 或手机提醒）
- [ ] 每天步数目标 6000 步
- [ ] 睡眠目标：固定起床时间，比上周提前 30 分钟上床

**不要做**：同时开始节食、跑 5 公里、每天健身房。两周只加这两件事。

## 第 3–6 周：调整结构

**主题：吃对顺序，动够次数。**

- [ ] 每餐先菜 → 再蛋白质 → 最后主食
- [ ] 午餐和晚餐各至少 200 g 蔬菜
- [ ] 主食的 1/3 换成全谷物或杂豆
- [ ] 每周 3 次有氧，每次 30 分钟（快走、慢跑、骑行、游泳）
- [ ] 每周 2 次力量训练（深蹲、俯卧撑、臀桥、划船、核心）
- [ ] 晚餐尽量 19:00 前结束；睡前 8 小时不喝咖啡
- [ ] 每天步数目标 8000 步
- [ ] 每周末记录体重、腰围、完成情况

## 第 7–12 周：加量与复盘

**主题：把运动变成默认日程，用数据调整。**

- [ ] 有氧累计每周 150–200 分钟
- [ ] 力量训练每周 2–3 次，每 1–2 周小幅加量
- [ ] 每天步数目标 8000–10000 步
- [ ] 保证 7–8 小时睡眠
- [ ] 第 12 周复查异常指标（按医生建议）
- [ ] 对比第 0 周数据：体重、腰围、步数、睡眠、指标变化
- [ ] 写下下一个 12 周要保留的习惯和要改的一个问题

## 外卖与聚餐策略

### 点外卖

- 优先选有**明确蛋白质 + 蔬菜**的套餐：轻食、盖饭加一份青菜、麻辣烫少油少丸子。
- 主食减半，或换成杂粮饭；汤底选清汤，不喝汤。
- 避开：糖醋、红烧、油炸、干锅、浓汤、含糖饮料套餐。
- 备注"少油少盐、不要额外加糖"。

### 便利店

- 组合：无糖酸奶 + 茶叶蛋 + 沙拉 + 全麦面包。
- 替代：关东煮选萝卜、海带、豆腐，少选丸子；不买含糖饮料和甜面包。

### 聚餐

- 先吃菜和蛋白质，再吃主食；喝酒前先吃东西。
- 酒精是尿酸和 TG 的共同敌人，能推就推；推不掉就限量，不喝甜酒和啤酒。
- 第二天恢复正常饮食，不要用"节食一天"补偿。

### 加班应急

- 20:00 后只吃轻食：酸奶、鸡蛋、水果、坚果，避免重油夜宵。
- 熬夜后第二天正常起床，午睡 20 分钟，不靠连续咖啡因硬撑。

## 常见失败原因与对策

| 失败方式 | 对策 |
| --- | --- |
| 一开始就全改，三天后放弃 | 一次只加一个习惯，两周后再加 |
| 周末报复性吃喝 | 允许一餐放松，但不要放松一整天 |
| 社交压力 | 提前说自己在控糖/戒酒，用无糖饮料代酒 |
| 加班打断运动 | 把运动拆成 10 分钟一段，累计达标 |
| 只看体重 | 同时看腰围、步数、睡眠和指标趋势 |
| 指标没变就放弃 | 代谢改善需要 3–6 个月，先看行为是否稳定 |

## 季度复盘

每 12 周问自己四个问题：

1. 哪个习惯已经不需要意志力了？
2. 哪个习惯反复失败，能不能换一种更小的做法？
3. 数据（体重、腰围、指标、睡眠）往哪个方向走？
4. 下一个 12 周只改哪一件事？
