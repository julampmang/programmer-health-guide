# 01 · 脂肪肝：肝上的"技术债"

> **一句话结论**：脂肪肝早期可逆。减重 5%–7% 就能显著改善，减重 10% 以上有机会逆转纤维化；第一步是戒掉含糖饮料，而不是买护肝片。

## 为什么程序员高发

非酒精性脂肪性肝病（NAFLD，近年也被称为 MASLD）在我国成人中的患病率约为 29%，而在长期久坐、外卖为主的 IT 从业者中，研究报道的比例可达 40%–50%。常见原因不是"吃得太油"，而是以下几件事叠加：

| 因素 | 发生了什么 |
| --- | --- |
| 能量过剩 | 久坐让每日总消耗偏低，奶茶、零食、夜宵让摄入持续超标 |
| 果糖过量 | 含糖饮料中的果糖主要在肝脏代谢，直接促进肝脏脂肪合成 |
| 胰岛素抵抗 | 肌肉长期不收缩，对胰岛素不敏感，肝脏被迫合成更多脂肪 |
| 昼夜节律紊乱 | 熬夜、倒班影响肝脏脂质代谢的节律 |
| 体重与腰围 | 中心型肥胖（男性腰围 ≥90 cm、女性 ≥85 cm）风险最高 |

瘦人也会得脂肪肝，但超重和中心型肥胖是更明确的危险信号。

## 怎么发现

多数人没有症状，靠体检发现。

- **肝功能**：ALT、AST、GGT。注意约一半脂肪肝患者转氨酶可以正常，正常不代表没有脂肪肝。
- **腹部超声**：最常用的初筛手段，能看到中重度脂肪肝，但对轻度脂肪肝不够敏感。
- **肝脏弹性检测（FibroScan）**：同时评估脂肪变和纤维化程度，比超声更客观；超声提示脂肪肝时可以和医生讨论加做。
- **CT / MRI**：准确性更高，一般不需要常规做。

建议：每年体检包含肝功能和腹部超声；如果超声提示脂肪肝，进一步评估纤维化风险。

## 怎么做

### 饮食：制造能量缺口，优化结构

1. **先戒含糖饮料**。奶茶、可乐、果汁、运动饮料是果糖的主要来源。用白水、无糖茶、黑咖啡替代。这一条通常比"少吃油"更有效。
2. **水果吃整果，不榨汁**。每天 200–350 g，优先低糖水果。
3. **每餐有蔬菜**。午餐和晚餐各至少 200 g，深色蔬菜占一半；膳食纤维目标每天 25–30 g。
4. **蛋白质吃够**。每天 1.0–1.5 g/kg 体重，优先鱼、鸡胸、鸡蛋、豆腐、低脂奶。蛋白质的食物热效应更高，也更抗饿。
5. **主食换一部分**。把 1/3–1/2 的白米白面换成糙米、燕麦、藜麦、杂豆。
6. **热量缺口 300–500 kcal/天**。不需要极端节食；每餐七分饱，晚餐尽量在 19:00 前结束。
7. **调整进食顺序**：先菜 → 再蛋白质 → 最后主食，有助于降低餐后血糖和甘油三酯峰值。

### 运动：有氧为主，力量为辅

- **有氧**：每周 150–200 分钟中等强度（快走、慢跑、游泳、骑行），这是减少肝脂最直接的方式。
- **抗阻**：每周 2–3 次，练大肌群（深蹲、硬拉、卧推、划船），增加肌肉量、提高基础代谢。
- **NEAT**：比"专门去健身"更容易坚持。每 50 分钟起身 5 分钟、午饭后走 10–15 分钟、能走楼梯就不坐电梯。详见 [04 久坐与运动](04-sedentary.md)。

关键数字：体重下降 **5%–7%** 可显著改善肝脂肪变，下降 **10% 以上** 有机会逆转纤维化。速度以每月 2–4 斤为宜，避免极低热量饮食。

## 目标与复查

| 项目 | 目标 |
| --- | --- |
| 体重 | 3–6 个月下降 5%–7%，之后维持 |
| 腰围 | 男 <90 cm，女 <85 cm |
| 有氧 | 每周 ≥150 分钟 |
| 抗阻 | 每周 2–3 次 |
| 复查 | 每 6–12 个月查肝功能 + 腹部超声；纤维化风险高者按医生建议缩短间隔 |

## 何时就医

- 转氨酶持续升高，或出现乏力、食欲下降、右上腹不适、皮肤或眼白发黄。
- 超声提示中重度脂肪肝，或 FibroScan 提示明显纤维化。
- 合并糖尿病、高血压、血脂异常、高尿酸，需要一起管理。
- 不要自行服用"保肝片""护肝片"替代生活方式干预，也不要自行停药。

## 常见问题

**Q：脂肪肝能完全逆转吗？**
早期单纯性脂肪肝在减重和运动后可以完全恢复；已经出现纤维化时，目标是阻止进展、争取逆转，需要医生随访。

**Q：只吃素能好吗？**
不一定。纯素饮食也可能高油高糖、蛋白质不足。关键在总热量、果糖和膳食纤维，而不是"有没有肉"。

**Q：需要吃护肝药吗？**
目前没有证据支持某种保健品能替代减重和运动。药物需由医生根据肝功能和纤维化程度决定。
