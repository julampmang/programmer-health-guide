# 07 · 年度体检清单：查什么、怎么读

> **一句话结论**：程序员体检的重点不是"项目越多越好"，而是覆盖**代谢、肝脏、肾脏、心血管和颈腰**这几条主线，并且把历年的报告放在一起看趋势。

## 基础项目（每年）

| 类别 | 项目 | 关注点 |
| --- | --- | --- |
| 体格 | 身高、体重、BMI、腰围、血压 | 中心型肥胖、高血压 |
| 血液 | 血常规 | 贫血、感染、血小板 |
| 肝脏 | ALT、AST、GGT、总胆红素、白蛋白 | 脂肪肝、酒精性肝损伤 |
| 肾脏 | 肌酐、eGFR、尿常规 | 高尿酸相关肾损伤、蛋白尿 |
| 代谢 | 空腹血糖、HbA1c、血脂四项、血尿酸 | 糖尿病、血脂异常、高尿酸 |
| 影像 | 腹部超声 | 脂肪肝、胆囊结石、肾结石 |
| 其他 | 心电图、胸部 X 线（或低剂量 CT，按吸烟史） | 心律失常、肺部病变 |

## 按年龄和风险加做

| 人群 | 建议加做 |
| --- | --- |
| 30 岁以上 | 颈动脉超声（有高血压/血脂异常/吸烟者） |
| 40 岁以上 | 胃肠镜（按家族史和医生建议）、眼底检查 |
| 长期吸烟 | 低剂量胸部 CT |
| 有痛风/肾结石 | 泌尿系超声、尿 pH、肾功能随访 |
| 打鼾伴白天嗜睡 | 睡眠监测 |
| 久坐 + 腰颈痛 | 由医生决定是否需要影像检查，不建议无症状常规拍片 |

## 频率

- 20–30 岁：每 1–2 年一次基础体检。
- 30–40 岁：每年一次；有异常指标者每 3–6 个月复查相关项目。
- 40 岁以上：每年一次，按风险增加专项筛查。
- 已有脂肪肝、糖尿病、高血压、高尿酸、血脂异常：按专科医生制定的随访计划，不要只等年度体检。

## 体检前准备

- 空腹 8–12 小时（可少量白水），前一晚避免饮酒、熬夜和剧烈运动。
- 正在服用的药物提前告知医生，不要自行停药。
- 女性避开月经期做尿常规。
- 带上往年报告，方便医生对比趋势。

## 报告怎么读

| 指标 | 一般参考 | 轻度异常怎么做 | 明显异常/症状 |
| --- | --- | --- | --- |
| ALT / AST | 约 7–40 U/L | 1–3 个月复查，戒酒、减重 | 持续升高或伴黄疸 → 消化/肝病科 |
| GGT | 约 7–45 U/L | 减少酒精、复查 | 明显升高 → 就医 |
| TG | <1.7 mmol/L | 3–6 个月生活方式干预后复查 | ≥5.6 需医生评估胰腺炎风险 |
| LDL-C | <3.4 mmol/L（一般） | 控制饮食、运动，3–6 个月复查 | 按危险分层决定是否用药 |
| 尿酸 | 男 <420，女 <360 μmol/L | 戒含糖饮料、多喝水、减重 | ≥540 或痛风发作 → 风湿/肾内科 |
| 空腹血糖 | 3.9–6.1 mmol/L | 6.1–6.9 做 OGTT，改善生活方式 | ≥7.0 → 内分泌科 |
| HbA1c | <5.7% | 5.7%–6.4% 为糖尿病前期 | ≥6.5% → 内分泌科 |
| eGFR | ≥90 | 轻度下降需复查、控制血压和尿酸 | 持续下降 → 肾内科 |
| 血压 | <120/80 理想 | 130–139/85–89 家庭监测 | ≥140/90 多次测量 → 心内科 |
| 腰围 | 男 <90 cm，女 <85 cm | 减重、增加活动 | 合并代谢异常 → 重点干预 |

> 参考范围因实验室和检测方法不同而不同，请以报告单上的参考区间为准。单项轻度异常不等于疾病，重点看**趋势**和**组合**。

## 建立自己的健康档案

建议用一个表格或笔记记录：

- 日期、体重、腰围、血压
- ALT、AST、GGT、TG、LDL-C、HDL-C、尿酸、空腹血糖、HbA1c、eGFR
- 当年的运动频率、睡眠时长、饮酒情况
- 医生建议与复查时间

每年更新一次，比只看"有没有箭头"更有价值。

## 常见问题

**Q：体检正常就代表健康吗？**
不代表。常规体检有漏检，参考范围也基于统计；有症状或家族史时，需要针对性检查。

**Q：肿瘤标志物要全查吗？**
不建议无症状人群盲目查全套肿瘤标志物，假阳性会带来不必要的焦虑和检查。按年龄、家族史和医生建议选择。

**Q：多久复查一次异常指标？**
轻度异常通常 3–6 个月复查；具体间隔由医生根据异常程度和病因决定。
