# 02 · 血脂异常：血液里的"坏味道"

> **一句话结论**：程序员最典型的模式是 **甘油三酯（TG）偏高 + 高密度脂蛋白（HDL-C）偏低**，根源是久坐、精制碳水和酒精。先改生活方式 3–6 个月，再谈药物。

## 先看懂四个指标

| 指标 | 一般参考 | 说明 |
| --- | --- | --- |
| 总胆固醇 TC | <5.2 mmol/L | 受 LDL 和 HDL 共同影响，单看意义有限 |
| 甘油三酯 TG | <1.7 mmol/L | 最能反映碳水、酒精和久坐的影响 |
| 低密度脂蛋白 LDL-C | 一般 <3.4 mmol/L | 动脉粥样硬化的主要危险因素，目标值分层 |
| 高密度脂蛋白 HDL-C | >1.0 mmol/L | "好胆固醇"，久坐和吸烟会把它拉低 |

LDL-C 的目标不是人人一样：

- 一般人群：<3.4 mmol/L
- 高危（糖尿病、高血压合并多个危险因素等）：<2.6 mmol/L
- 极高危（已确诊冠心病、脑卒中等动脉粥样硬化性心血管疾病）：<1.8 mmol/L，部分患者更低

具体分层请让医生结合年龄、血压、吸烟、糖尿病等综合判断。

## 为什么程序员容易中招

- **久坐**：肌肉摄取游离脂肪酸减少，TG 清除率下降，HDL-C 合成减少。
- **精制碳水**：白米饭、面条、面包、甜点、含糖饮料过多，肝脏合成 TG 增加。
- **酒精**：尤其是啤酒和甜酒，直接升高 TG。
- **超重与胰岛素抵抗**：脂肪组织释放更多游离脂肪酸进入血液。
- **遗传**：家族性高胆固醇血症并不少见，年轻、瘦也可能 LDL 很高。

## 怎么做

### 饮食

1. **控制精制碳水**：主食的 1/3–1/2 换成全谷物、杂豆；减少甜点和含糖饮料。
2. **增加膳食纤维**：每天 25–30 g，来自蔬菜、全谷物、豆类。
3. **Omega-3**：每周 2–3 次深海鱼（三文鱼、鲭鱼、秋刀鱼）。如果吃不到，和医生讨论补充剂；高剂量鱼油对 TG 的降幅可达 20%–50%，但需要医生指导。
4. **植物甾醇**：每天一小把坚果（约 25 g）、豆制品、全谷物，有助于降低 LDL-C。
5. **限制酒精**：TG 明显升高时建议完全戒酒。
6. **进食顺序**：先菜 → 蛋白质 → 主食，降低餐后 TG 峰值。

### 运动

- **有氧**：每周 ≥150 分钟中等强度，可使 TG 降低约 10%–30%，HDL-C 升高约 5%–15%。
- **HIIT**：时间紧时可选，例如 20 分钟（30 秒冲刺 + 60 秒慢走，重复 13 次），每周 3 次；有心血管风险者先咨询医生。
- **抗阻**：每周 2 次，改善胰岛素敏感性。
- 效果需要 3–6 个月持续运动才能充分体现，别两周没变化就放弃。

### 体重与习惯

- 减重 5%–10% 可显著改善 TG 和 HDL-C。
- 戒烟：吸烟会降低 HDL-C。
- 保证睡眠：睡眠不足会升高 TG 和食欲。

## 目标与复查

| 项目 | 目标 |
| --- | --- |
| TG | <1.7 mmol/L |
| HDL-C | >1.0 mmol/L |
| LDL-C | 按医生评估的危险分层 |
| 复查 | 生活方式干预后 3–6 个月复查血脂四项 |

## 何时就医

- LDL-C 明显升高（如 ≥4.9 mmol/L），或有早发心血管病家族史。
- 已确诊糖尿病、高血压、冠心病、脑卒中。
- 规范生活方式 3–6 个月后血脂仍不达标。
- 出现胸痛、胸闷、活动后气短等症状，立即就医。

他汀等降脂药需要医生评估肝肾功能和相互作用，不要自行购买服用。

## 常见问题

**Q：我很瘦，为什么血脂还高？**
血脂受遗传影响很大，瘦人也会有家族性高胆固醇血症。瘦不等于代谢健康。

**Q：不吃肉是不是就好了？**
不一定。高碳水、高糖、酒精同样会升高 TG。关键是整体结构。

**Q：鱼油能代替药吗？**
不能。处方级鱼油有特定适应症，普通保健品剂量和纯度差异大，需医生评估。
