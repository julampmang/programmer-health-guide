# 03 · 高尿酸与痛风："富贵病"的年轻化

> **一句话结论**：对程序员来说，果糖和酒精对尿酸的影响往往比海鲜更大。把含糖饮料戒掉、每天喝够 2–3 L 水、控制减重速度，通常比"忌口海鲜"更有效。

## 阈值与目标

| 人群 | 血尿酸水平 |
| --- | --- |
| 男性 | ≥420 μmol/L（非同日两次空腹） |
| 女性 | ≥360 μmol/L（非同日两次空腹） |
| 痛风患者降尿酸目标 | <360 μmol/L |
| 有痛风石或频繁发作者 | <300 μmol/L |

高尿酸不只是痛风的前奏，还与高血压、慢性肾病、心血管疾病相关。很多人第一次痛风发作前，尿酸已经偏高多年而不知情。

## 为什么程序员容易高

- **含糖饮料**：果糖在肝脏代谢时消耗 ATP，产生尿酸前体。每天 2 杯以上含糖饮料的人，高尿酸风险显著增加。
- **久坐**：活动量低，尿酸肾脏排泄效率下降。
- **超重**：脂肪组织促进尿酸合成、抑制排泄。
- **酒精**：啤酒既含嘌呤又抑制尿酸排泄；烈酒同样升高风险。
- **熬夜与脱水**：饮水不足让尿酸浓度升高。
- **快速减重 / 生酮饮食**：酮体与尿酸竞争排泄，可能诱发痛风。
- **药物**：噻嗪类利尿剂、小剂量阿司匹林等可能影响尿酸，需医生评估。

## 怎么做

### 饮食（大约占尿酸控制的 30%）

1. **戒含糖饮料和果汁**：优先级最高，包括"无糖"标签但含果葡糖浆的饮料。
2. **喝够水**：每天 2000–3000 mL 白水或淡茶，分次喝；心肾功能不全者遵医嘱。
3. **限制高嘌呤食物**：动物内脏、浓肉汤、火锅老汤、沙丁鱼、凤尾鱼、带壳类海鲜尽量少吃；红肉每天控制在 100 g 以内。
4. **豆制品不必一刀切**：豆腐、豆浆的嘌呤含量中等，流行病学研究未显示明显增加痛风风险，可适量吃。
5. **低脂乳制品**：每天 250–500 mL 低脂奶或酸奶，有助于尿酸排泄。
6. **咖啡**：适量咖啡与较低痛风风险相关，但别用含糖咖啡饮料替代。
7. **严格限酒**：啤酒和烈酒尽量避免；痛风急性期完全戒酒。
8. **水果适量**：果糖同样来自水果，每天 200–350 g，不榨汁。

### 生活方式（大约占 70%）

- **减重**：BMI 每下降 1，血尿酸可下降约 10–20 μmol/L。但速度控制在每月 2–4 斤，避免极低热量和生酮。
- **规律中等强度运动**：每周 150 分钟有氧；避免突然剧烈运动、脱水和运动后暴饮啤酒。
- **规律作息**：尽量 23:00 前入睡，保证 7–8 小时睡眠。
- **碱化尿液**：医生可能建议监测尿 pH（目标约 6.2–6.9），不要自行长期大量服小苏打。

## 何时就医

- 关节突然红、肿、热、痛，尤其是大脚趾、踝、膝，怀疑痛风急性发作。
- 血尿酸 ≥540 μmol/L，或反复发作、有痛风石、肾结石。
- 出现腰痛、血尿、肾功能下降（eGFR 降低）。
- 正在服用利尿剂、抗结核药等可能影响尿酸的药物。

降尿酸药（别嘌醇、非布司他、苯溴马隆等）有明确适应症和风险，必须由医生开具并随访。**急性发作期不要自行加用或停用降尿酸药**，按医嘱处理。

## 常见问题

**Q：尿酸高就一定会痛风吗？**
不一定。只有部分高尿酸者会发作痛风，但尿酸越高、持续时间越长，风险越大，同时肾脏和心血管风险也在增加。

**Q：不吃海鲜就行了吗？**
果糖、酒精、体重和遗传的影响往往更大。只忌海鲜、继续喝奶茶，效果有限。

**Q：痛风发作时能运动吗？**
急性期休息、抬高患肢、避免负重；缓解期再逐步恢复中等强度运动。
